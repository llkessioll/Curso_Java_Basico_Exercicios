# 📚 Exercícios de Java Básico

Este repositório contém exercícios desenvolvidos durante meus estudos em **Java Básico**, com foco em lógica de programação, estruturas de controle, arrays, matrizes e conceitos iniciais de orientação a objetos.

Os exercícios foram feitos como prática para fixação do conteúdo e evolução gradual no aprendizado da linguagem Java.

---

## 🧠 Conteúdos Praticados

- ✅ Variáveis e tipos de dados  
- ✅ Estruturas condicionais (`if`, `else`, `switch`)  
- ✅ Estruturas de repetição (`for`, `while`, `do-while`)  
- ✅ Arrays (vetores)  
- ✅ Matrizes  
- ✅ Métodos  
- ✅ Métodos estáticos  
- ✅ Orientação a Objetos  
  - Classes  
  - Atributos  
  - Métodos  
  - Construtores  
  - Encapsulamento  
- ✅ Exercícios práticos (ex: Jogo da Velha, Calculadora, Agenda, etc.)

1. Clone o repositório:

git clone https://github.com/llkessioll/Curso_Java_Basico_Exercicios.git

2. Abra o projeto em uma IDE Java:

Eclipse

VS Code (com extensão Java)

3. Execute as classes que possuem o método main.
